Revit workflow

Export OBJ and MTL to the same folder. Open a Metric Furniture family (or Generic Model) in Revit and use Insert → Import CAD → OBJ. Set units to millimetres, confirm orientation and dimensions, then save as RFA and load into the project. Materials may require reassignment. Each export is static geometry; the HTML controls are not native Revit parameters.

Reference design

A curved oak enclosure with a continuous upholstered bench and a central collaboration table, inspired by the supplied reference. Dimensions and palette are design assumptions. No structural, accessibility, upholstery fire-performance or acoustic certification is implied.
