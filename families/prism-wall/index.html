Revit workflow

Export OBJ and MTL into the same folder without renaming. Revit: New Family → Metric Generic Model → Insert → Import CAD → OBJ; verify millimetres, assign glass materials if needed. For a wall-hosted RFA use a face-based template; individual exports are centered in XY with base at Z=0, save RFA and Load into Project. Check glass, supports and fire / impact requirements with specialists before fabrication. Fully offline.
