Revit workflow

Export OBJ and MTL into the same folder. Create a Metric Generic Model face based family for a straight wall, or Metric Generic Model for corner/freestanding layouts. Insert → Import CAD → OBJ, verify millimetres, orientation and materials. Save RFA and load into project. Floor Z=0, main wall rear face Y=0; front is negative Y. Geometry is static, not an operating touchscreen system. Verify fixing, ventilation, electrical safety, reach ranges and clearances separately.
