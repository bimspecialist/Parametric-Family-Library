Revit workflow / الاستيراد

Export OBJ and MTL into the same directory. In Revit: File → New → Family → Metric Generic Model.rft → Insert → Import CAD → OBJ. Choose millimetres and origin-to-origin if offered. Check the elevation dimensions; save as RFA and load into the project. MTL is a colour reference; Revit may require manual material assignment. The original sandstone colour, bump and roughness maps are supplied separately in the ZIP package. The relief is generated geometry; heritage imagery, projectors, lighting and support structure are not included.

الأبعاد تُعدل هنا قبل التصدير، وليست بارامترات حية داخل Revit. راجع أقصى بروز والمسافة المتاحة بجانب السلم الكهربائي قبل اعتماد التصميم.
