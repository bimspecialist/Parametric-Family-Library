Integrated seating / جلسة مدمجة

3D concept preview

OBJ import: export OBJ and MTL into the same folder, then import OBJ into a Metric Generic Model family. Check units and dimensions, then save as RFA.

Native geometry: export TSV for the optional Revit 2027 builder. To change dimensions, regenerate the geometry; neither imported OBJ nor FreeForm geometry is live-parametric inside Family Types. TSV is available for the original wall without seating. For integrated seating use OBJ; it includes the modified fins and continuous seat surface. Preview is schematic; structural support, upholstery and lighting are not included.
