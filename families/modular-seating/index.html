Revit workflow

Use Export selection → Choose any individual piece, then select a numbered bench, ottoman or side table. Existing full-arrangement and first-piece exports are also available. Export OBJ and MTL to the same folder. In Revit: File → New → Family → Metric Furniture (or Generic Model) → Insert → Import CAD → OBJ. Confirm millimetres, materials and origin; save as RFA. Geometry is static after import. Floor clearance, upholstery, supports and fire performance require design review; this tool does not certify furniture.

Design reference

Backless angular upholstered benches, rounded barrel ottomans and dark cantilever laptop tables, based on the supplied image. All dimensions and colors are editable design assumptions, not measured manufacturer specifications.
