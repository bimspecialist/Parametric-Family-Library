Revit workflow

Export ZIP and extract all files into the same folder. In Revit, use Metric Generic Model for the wall and Metric Furniture for the table or stools. Use Insert → Import CAD → OBJ, verify millimetres and orientation, save RFA, then Load into Project. OBJ is static; textures may need manual assignment in Revit. Screen artwork is exported as PNG. Lighting, touch and idea workflow are conceptual only. Verify reach, mounting, electrical service, ventilation and circulation before implementation.
