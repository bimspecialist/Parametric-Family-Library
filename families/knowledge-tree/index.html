Revit workflow

Export OBJ and MTL into the same folder. Open Metric Generic Model family in Revit → Insert → Import CAD → OBJ. Verify millimetres, assign materials if required, save RFA, and Load into Project. Model origin is trunk centre at floor level (Z=0). Geometry is static; discipline selection is a browser demonstration, not a connected lighting system. Structural support, electrical coordination, fire performance and clearances require engineering review.
